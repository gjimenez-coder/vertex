# Development of Microservices Using NestJS: Architecture and Practical Examples

Autor: V. Dolzhenko (Universum: Technical Sciences, 2024)

Artículo compacto que presenta NestJS —framework basado en Node.js y TypeScript que se apoya en Express y el patrón MVC— como herramienta para desarrollar microservicios. Explica los elementos básicos de una aplicación NestJS (módulos, controladores y servicios), cómo la arquitectura de microservicios responde a los problemas del desarrollo monolítico, los protocolos de comunicación que admite y el papel de Docker en el despliegue. Destaca la inyección de dependencias y los decoradores de TypeScript como rasgos que favorecen aplicaciones modulares, testeables y escalables.

## Capítulos
